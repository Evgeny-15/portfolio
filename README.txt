ПОРТФОЛИО Evgeny.dev — ИНСТРУКЦИЯ

1. ЧТО ВНУТРИ
- index.html — разметка сайта
- style.css — оформление и адаптивность
- script.js — меню, фильтры, окна проектов, форма связи

2. КАК ЗАПУСТИТЬ В VS CODE (Windows 11)
1) Распакуйте архив в удобную папку, например Рабочий стол\portfolio.
2) Откройте VS Code.
3) Выберите Файл → Открыть папку и укажите папку portfolio.
4) Откройте index.html.
5) Самый простой способ — открыть index.html двойным щелчком в Проводнике.
   Для удобной разработки установите расширение Live Server:
   - слева нажмите «Расширения»;
   - найдите Live Server от Ritwick Dey;
   - нажмите Install;
   - откройте index.html, нажмите правой кнопкой и выберите
     Open with Live Server.
6) После изменения кода сохраните файл Ctrl+S. Live Server обновит страницу.

3. ЧТО ПРОВЕРИТЬ
- Нажмите пункты меню — они прокручивают страницу к разделам.
- На узком окне браузера проверьте кнопку меню.
- В разделе «Проекты» переключите фильтры.
- Нажмите «Подробнее» в любой карточке.
- Заполните контактную форму. Она попытается открыть почтовое приложение.
- Проверьте адаптивность: нажмите F12 и включите режим мобильного устройства.

4. ПЕРЕД ПУБЛИКАЦИЕЙ
- Замените имя «Евгений» и evgeny.dev на свои данные.
- В index.html замените ссылку Telegram https://t.me/ на свой профиль.
- Замените your-email@example.com на свой настоящий email (в index.html и script.js).
- Демонстрационные проекты прямо обозначены как концепты. Не представляйте их как заказы реальных клиентов.
- В разделе навыков укажите только то, что действительно умеете.
- Форма mailto: не отправляет данные на сервер сама по себе. Она открывает почтовое приложение; для настоящей онлайн-формы понадобится сервер или внешний сервис форм.

5. ИЗОБРАЖЕНИЯ И ШРИФТЫ
Этот вариант сделан без внешних фотографий, чтобы сайт работал сразу и не ломался из-за отсутствующих файлов. Шрифт Manrope загружается из Google Fonts при наличии интернета; без интернета будет использован системный шрифт.

Удачи! Начните с замены имени, email и Telegram, а затем добавляйте собственные работы.
